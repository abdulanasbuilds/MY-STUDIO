# MY STUDIO — API Documentation

> API documentation is generated as modules are built.

## Base URL

- **Frontend API:** `https://your-app.vercel.app/api/`
- **Modal Backend:** `https://your-app--my-studio.modal.run/`

## Authentication

All API routes require authentication via Supabase session cookies.
Modal endpoints require `api_token` and `timestamp` in the request body.
