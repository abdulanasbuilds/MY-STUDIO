## Quick Reference

- **Frontend:** Next.js 14 on Vercel
- **Backend:** Python 3.11 on Modal.com
- **Database:** Supabase (PostgreSQL + Auth + RLS)
- **Edge:** Cloudflare Workers
- **Storage:** Cloudinary
- **Queue:** Upstash Redis
