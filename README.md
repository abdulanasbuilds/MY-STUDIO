# MY STUDIO

The world's most powerful open source AI content creation platform.

Built by [@abdulanasbuilds](https://github.com/abdulanasbuilds) in Ghana.

## What It Does

Takes any input — text, URL, video, audio, article, or idea — and produces professional-grade video content. Combines 50+ open source AI models into one platform.

**Replaces $486+/month of tools at zero cost.**

## Tech Stack

- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS
- **Backend:** Python 3.11 + Modal.com (GPU)
- **Database:** Supabase (PostgreSQL + Auth + RLS)
- **Edge:** Cloudflare Workers
- **Storage:** Cloudinary

## Getting Started

```bash
git clone https://github.com/abdulanasbuilds/my-studio.git
cd my-studio
bash scripts/setup.sh
npm run dev
```
